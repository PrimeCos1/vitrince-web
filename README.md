# vitrince-web

Website von Vitrince Adana (https://vitrince.tr). Statische Seite, ausgeliefert mit nginx hinter Traefik auf dem Hostinger-VPS.

- `site/` – Website (HTML, Bilder, Schriften)
- `nginx/` – Server-Konfiguration (keine Zugriffsprotokolle, Sicherheits-Header)
- `docker-compose.yml` – Deployment über den Hostinger-MCP
